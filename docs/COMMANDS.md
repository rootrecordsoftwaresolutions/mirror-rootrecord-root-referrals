# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/root` | Referral code, claim, info, tree, and leaderboard | `` | `/<command> [code/claim/info/tree/top/admin ...]` |
| `/rootreferrals` | Admin reload for Root-Referrals | `` | `/<command> reload` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootreferrals.use` | Use /root referral commands | `true` |
| `rootreferrals.claim` | Claim a referral code | `true` |
| `rootreferrals.admin` | Admin inspect, unlink, purge, qualify, reload | `op` |
